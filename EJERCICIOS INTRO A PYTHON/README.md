# Ejercicios de Introducción a Python 🐍

Este repositorio contiene los **20 ejercicios de la guía de Introducción a Python**, organizados en archivos `ejercicio1.py` hasta `ejercicio20.py`.

## 📂 Contenido

- **ejercicio1.py** → Precio de entrada según edad.
- **ejercicio2.py** → Asignación de grupos A y B según nombre y sexo.
- **ejercicio3.py** → Reforma tributaria: cálculo de impuesto según salario.
- **ejercicio4.py** → (Ejercicio de condicionales básicos).
- **ejercicio5.py** → Lista de palabras y conteo de ocurrencias.
- **ejercicio6.py** → Pizzería Napolitana: elección de ingredientes.
- **ejercicio7.py** → Fases de vacunación según edad.
- **ejercicio8.py** → Factorial de un número (recursivo).
- **ejercicio9.py** → Lista de números aleatorios y ordenamiento.
- **ejercicio10.py** → (Ejercicio de bucles).
- **ejercicio11.py** → (Ejercicio de condicionales).
- **ejercicio12.py** → (Operaciones matemáticas).
- **ejercicio13.py** → (Listas o cadenas).
- **ejercicio14.py** → Días de un mes específico.
- **ejercicio15.py** → Separar pares e impares en listas.
- **ejercicio16.py** → Verificar triángulo y tipo.
- **ejercicio17.py** → Factorial (otra versión).
- **ejercicio18.py** → Clases Carro y Libro.
- **ejercicio19.py** → Clases Animal, Pez, Perro, Gato (herencia).
- **ejercicio20.py** → Clase Vuelo con pasajeros.
