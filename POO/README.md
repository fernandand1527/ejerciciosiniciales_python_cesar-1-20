# 🐍 Clases de Python - CESAR

Este repositorio contiene diferentes **clases y ejercicios de Python**, organizados por temas:

---

## 📂 Contenido

- **Ejercicios introductorios (01–20):**  
  Condicionales, bucles, listas, sets, manejo de JSON.

- **POO (Programación Orientada a Objetos):**  
  Ejemplos prácticos con clases como `Carro`, `Palabra`, `Diccionario`.

- **DICCIONARIO:**  
  Implementación de clases para gestionar palabras y diccionarios.

- **MYSQL-Crud:**  
  Conexión a MySQL con PyMySQL y operaciones CRUD sobre la tabla `productos`.

---

## 🚀 Requisitos generales
- Python 3.10+  
- MySQL Server (para el módulo CRUD)  
- Librería PyMySQL → `pip install pymysql`

---

Cada carpeta contiene sus propios scripts.
